# Writing

Use the ASD-STE100 guide at `~/.claude/skills/asd-ste100/SKILL.md` when available.

- Remove text unless the user needs it to act.
- Use short, plain sentences.
- Do not add taglines, sales copy, tips, or praise.
- Use labels on controls. Add help text only when a control needs it.

# Editor

- Match the black controls in `../uidesigneditor/editor/shadcn.css`.
- Edit a separate page copy. Do not change source page elements.
- Allow free movement. Keep the position of other items unchanged.
- Keep each item free of its source parents. Keep the same layer order.
- Move items together only when the user selects them together or makes a group.
- Start each edit session from the current page. Save drafts only when storage is on.
- Put text, background, and border colors first in the sidebar.
- Use color pickers, sliders, buttons, and lists. Keep color fields for copy and paste.
- Put Border after text and before Font.
- Open edit mode at 80%.
- Ask twice before the user resets the page.
- Skip items that fully surround the selection box. Select them when the box crosses their edge.
- Use the bottom-right handle to scale the item and its contents.
- Use side handles to resize the box.
- Keep the add tools in a separate left sidebar. Use the same tools and icons as the UI design editor.
- Keep text in place when fitting its box to content.
- Include new items in undo, redo, saved drafts, and exports.
- Copied instructions must use canvas edits as the visual target. Change the real layout rather than copying canvas coordinates literally.
