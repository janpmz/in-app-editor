# Setup prompt

Paste this into Codex in your website project:

```text
Add the edit mode from https://github.com/janpmz/in-app-editor to this website.
Read its README and use the latest main branch.
Copy in-app-editor.js and LICENSE into this project.
Load the editor once in the browser after the page is ready.
Use this project's current setup. The editor needs no separate server.
Show the EDIT button in local builds and private previews only.
Keep the site's design and behavior unchanged outside edit mode.
Use the editor's separate page copy for free movement and visual edits.
Keep draft storage off so each edit session starts from the current page.
Do not add the repo's demo page to this site.
Check selection, movement, scaling, text edits, undo, and exit.
```

After editing, click **copy change instructions**. Paste those instructions into Codex in the same website project. Codex then applies the edits to the site's files through the real page layout.
